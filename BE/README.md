# Back-End Server - Royal Bistro Restaurant Management

## Khởi chạy nhanh
```bash
# Cài đặt thư viện
npm install

# Khởi chạy máy chủ development
npm run dev
```

Cổng mặc định: `http://localhost:5000` (hoặc cấu hình tại `.env`).
